# 图形推理 · 功法（薛睿图推 24 诀）

> 审改说明：一个 `## 标题` = 一诀（一重功法）。每一诀练三件事：
> - `【特征】`：这一诀适用的图形长什么样（说出大意即可）；
> - `【口诀】`：口诀原句，**必须一字不差**（整句逐字比对，标点不算）；
> - `【翻译】`：每句口诀是什么意思、具体看什么（说出大意即可）。

## 第一诀 一根线
- 【特征】用一条连续的、不重复的线条一笔画成的图形
- 【口诀】先看对称一笔画
- 【口诀】数面数线数交点
- 【口诀】图形抽象看曲直
- 【口诀】直角平行部分数
- 【口诀】有灵魂的一根线
- 【翻译】先看对称一笔画：对称——轴对称、中心对称、对称轴数量及方向、对称轴过线/点/面（特征：图形非常规则）；一笔画——点连接图形、外部轮廓凌乱、线段出头、常见图形变形（日、田、目）、圆套圆
- 【翻译】数面数线数交点：面、线、点都看数量相同或数量递增（面注意以 0 面开始）
- 【翻译】图形抽象看曲直：曲+直、纯直、纯曲、曲直数量
- 【翻译】直角平行部分数：直角——数量相同、递增（特征：明显的横平竖直、直角三角形、矩形多、电话卡即其中一个角被切掉）；平行——有多少组平行（特征：梯形、矩形、两个相似三角形）；部分数——一根线通常以一部分开头
- 【翻译】有灵魂的一根线：考线段数量、曲直性、首尾线段平行/垂直、线段方向一致/相反、直角数量/旋转（特征：图形有明显的首尾线段）

## 第二诀 封闭面内一根线
- 【特征】一个闭合的平面区域，内部有一条连续的线段，线段首尾两点都与封闭面的边界相连
- 【口诀】封闭图形不要怕，一根线先一笔画
- 【口诀】有面仅相交于点，直接无脑去掉它
- 【翻译】封闭图形不要怕，一根线先一笔画：先把它当“一根线”，优先考一笔画
- 【翻译】有面仅相交于点，直接无脑去掉它（非典型）：只以一个点和线条相交的那个面，去掉框后看内部线条是几笔画

## 第三诀 一个面
- 【特征】由线条围成的一个封闭的连续区域
- 【口诀】对称数面一笔画
- 【口诀】规则面数线点角
- 【口诀】不规则面看曲直
- 【口诀】难题需要做加减
- 【翻译】对称数面一笔画：对称——轴对称、中心对称、对称轴数量及方向、对称轴过线/点/面（特征：图形非常规则）；数面——通常以一个面开头（特征：会在面内加线段，但不与边框接触）；一笔画（特征：图形线段很多，通常带个尖尖的箭头）
- 【翻译】规则面数线点角：线——数量相同、递增（特征：首个图形非常简单）；点——数量相同、递增（特征：递增时第二个图形多一条线、增加一个点）；角——直角数量
- 【翻译】不规则面看曲直：曲直性、曲直数量、曲曲挨在一起、曲曲间隔（曲直曲）
- 【翻译】难题需要做加减：两种属性做加减——数线、面、点、直角

## 第四诀 两根线
- 【特征】两条保持相对独立、能被视觉区分开的线条
- 【口诀】对称数面一笔画
- 【口诀】看完曲直数交点
- 【口诀】有灵魂的两根线
- 【翻译】对称数面一笔画：对称——轴对称、中心对称、对称轴数量及方向、过线/点/面；数面——数量相同、递增（特征：一条波浪线插入一条直线）；一笔画——通常是两笔画
- 【翻译】看完曲直数交点：曲直——曲+直、纯直、纯曲、曲直数量；再数交点数量
- 【翻译】有灵魂的两根线：线段数、交点数、交点的位置

## 第五诀 相交圆
- 【特征】若干个圆（或椭圆）通过相交（有公共点或重叠区域）组合成的平面图形
- 【口诀】对称数面一笔画
- 【口诀】看完曲直数交点
- 【翻译】对称数面一笔画：对称——轴对称、中心对称、对称轴数量及方向、过线/点/面（特征：图形非常规则）；数面——数量相同、递增；一笔画——不管套多少个圆，都是一笔画
- 【翻译】看完曲直数交点：曲直——曲+直、纯直、纯曲、曲直数量；交点数量——相切以一个交点开头，相交以两个交点开头

## 第六诀 均有圆
- 【特征】一组图形中，全部或多个图形都包含圆
- 【口诀】均有圆整体先看
- 【口诀】圆内圆外要分辨
- 【口诀】只看曲线交切点
- 【口诀】去掉圆把直线算
- 【翻译】均有圆整体先看：先看圆与其他部分的相交方式——相交、相切、相离
- 【翻译】圆内圆外要分辨：圆内交点数量（特征：一个完整的圆，乱七八糟的线穿过圆）；圆内面数量
- 【翻译】只看曲线交切点：数圆或圆弧上的切点；仅看曲直交点，不看直直交点
- 【翻译】去掉圆把直线算：只数直线
- 【翻译】非典型：交点位置（相交于圆弧中间或边）；圆的位置（圆在方框内，或圆有部分外露）；圆内的面与外轮廓都相邻 / 圆内有面与外轮廓不相邻

## 第七诀 对称性图形
- 【特征】图形明显对称：常由非常正规的等腰三角形、四边形、五边形等组成
- 【口诀】万物皆可考对称
- 【口诀】轴与中心要辨明
- 【口诀】数量方向依次数
- 【口诀】重叠方式最后评
- 【翻译】万物皆可考对称：先分对称与不对称（注意：带斜杠的阴影一般是不对称的）
- 【翻译】轴与中心要辨明：分清轴对称、中心对称、轴对称+中心对称；风车类图形——奇数角仅轴对称、不中心对称，偶数角既轴对称又中心对称；“不对称单叶”风车——奇数角不对称，偶数角仅中心对称 ⚠风车类放在这一句下是按逻辑推断的
- 【翻译】数量方向依次数：对称轴数量（特征：非常正规的等腰三角形、四边形、五边形等组成）、对称轴方向
- 【翻译】重叠方式最后评：对称轴与点、线重叠（过点还是过线）
- 【翻译】非典型：对称看一半——1. ABCDE 这类；2. 字母本身也是对称的

## 第八诀 笑脸类
- 【特征】以圆形为基本轮廓，用简化的线条或几何形状表现眼睛与嘴巴
- 【口诀】笑脸先看对称轴
- 【口诀】曲直部分心中有
- 【口诀】鼻嘴眼型莫疏漏
- 【翻译】笑脸先看对称轴：轴对称、中心对称、对称轴数量及方向、过线/点/面（特征：图形非常规则）
- 【翻译】曲直部分心中有：曲直——纯曲、纯直、曲直数量；部分数——笑脸一般是 4 部分或 5 部分
- 【翻译】鼻嘴眼型莫疏漏：鼻子和眼睛是某个特定的子图形，如三角形

## 第九诀 两图形分两部分
- 【特征】所有图都由两个独立的几何图形构成
- 【口诀】图形分成两部分
- 【口诀】相离单独看样式
- 【口诀】数量特征放心间
- 【口诀】重叠莫忘重叠面
- 【口诀】相交关注相交边
- 【翻译】图形分成两部分：先看对称——轴对称、中心对称、两部分对称轴平行/垂直
- 【翻译】相离单独看样式：两部分分开时，看一笔画、曲直性
- 【翻译】数量特征放心间：数量——直线（分开两部分数边）、数面、交点
- 【翻译】重叠莫忘重叠面：重叠面的边数、有无重叠面（特征：重叠面一般很大，方便数边数）；两个相似图形重叠
- 【翻译】相交关注相交边：连接方式——点连接、线连接；相邻边数——重合边的边数（特征：两部分完美贴合或部分贴合）；相交于图形的长边还是短边
- 【翻译】非典型：重合边形成的夹角是直角还是锐角

## 第十诀 两图形分内外框
- 【特征】图形由两个部分构成：一个“外框”（外部轮廓），一个“内框”（内部轮廓）
- 【口诀】图形分成内外框
- 【口诀】内外单独看样式
- 【口诀】数量特征放心间
- 【口诀】仅看框或去框看
- 【口诀】内外互换有概念
- 【翻译】图形分成内外框：先看对称——内外框是轴对称/中心对称
- 【翻译】内外单独看样式：曲直性——外直内曲、外曲内直
- 【翻译】数量特征放心间：直线数——内外框直线数的加减运算；外框上的交点数、外框上的交点位置（上下左右）⚠“外框上的交点”也可能是本诀“非典型”一行，原表这一行的内容没识别清楚
- 【翻译】仅看框或去框看：去掉框后，看内部图形规律（如点连接还是线连接）
- 【翻译】内外互换有概念：第一图的外框到第二/第三图，第二图的内框到第三图

## 第十一诀 均有封闭多边形外框
- 【特征】每个图都有一个封闭的多边形外框
- 【口诀】封闭外框是题眼
- 【口诀】边面同数为关键
- 【口诀】相同最大要敏感
- 【口诀】框内框外点与线
- 【口诀】三角形面莫数偏
- 【口诀】曲平直角细分辨
- 【翻译】封闭外框是题眼：外框的直角数；外框边数（其中一个外框是圆时不用数；特征：外框边数变化明显）；外框对称性
- 【翻译】边面同数为关键：外框边数与面数做加减（往往外框边数 = 面数，或多 1 个）
- 【翻译】相同最大要敏感：观察子图形有没有明显的最大面、相同子图形、对称性子图形；最大面/最小面——1. 最大面跟外框一样 2. 最大面的边数递增 3. 最大面是轴对称/中心对称图形 4. 最大面均是三角形/四边形（特征：题目和选项都有明显的最大面最小面）
- 【翻译】框内框外点与线：框上交点数、框内交点数、框内直线数分开数，往往做加减（特征：外框边数基本一致）
- 【翻译】三角形面莫数偏：三角形数量（特征：第一个图是三角形，每图均有三角形）
- 【翻译】曲平直角细分辨：直角（特征：多直角三角形、矩形、直角梯形）、有无曲线、有无平行
- 【翻译】非典型：内部有一个面不与外框接触

## 第十二诀 相同样式之有重复的独立小图形
- 【特征】图中有很多重复出现的独立小图形
- 【口诀】好多重复小图形
- 【口诀】数量转化要算清
- 【口诀】种类遍历依次看
- 【口诀】旋转相接定输赢
- 【翻译】好多重复小图形：一组图——1. 每个图单独看数字 2. 样式/数字交替 3. 两样式的加减 4. 邻图比较（两两比较找规律，如有几个相同样式）；两组图/九宫格——1. 三幅图数字运算（前两图加减 = 后一幅） 2. 图1 + 图2 = 图3 3. 所有图当作整体看
- 【翻译】数量转化要算清：样式数量转换（方法：图1 + 图3 = 2 倍图2；特征：种类数基本一致，数量明显递增，但直接数无规律）
- 【翻译】种类遍历依次看：样式种类数；样式遍历——图形都要出现过、出现次数一致（特征：种类数一致且很少）
- 【翻译】旋转相接定输赢：平移旋转；样式位置（相接方式）——左上右下、右上左下

## 第十三诀 相同样式之图形整体/轮廓相同
- 【特征】一组图的整体或外轮廓相同
- 【口诀】整体轮廓若相同
- 【口诀】有黑有白算黑白
- 【口诀】全图相同看旋转
- 【口诀】子图相同做平移
- 【翻译】整体轮廓若相同：轮廓一样时，先分有没有黑白、是全图相同还是子图相同
- 【翻译】有黑有白算黑白：黑白运算（特征：只出现在两组图、九宫格，外轮廓一致，前后黑白位置差不多）
- 【翻译】全图相同看旋转：旋转/翻转——1. 整体图形旋转 2. 子图形分别旋转 3. 内圈外圈旋转
- 【翻译】子图相同做平移：子图形平移——直线移动、绕圈移动
- 【翻译】样式遍历：样式都要出现过，出现的次数一致 ⚠原表这一行放在第十三诀末尾，口诀列只写了“样式遍历”

## 第十四诀 相同样式之相同位置有相同线条
- 【特征】几幅图在相同位置有相同的线条
- 【口诀】相同位置线条重
- 【口诀】三图叠加或求同
- 【口诀】两图相同做求异
- 【口诀】邻图对比莫忘记
- 【翻译】相同位置线条重：相同位置有重复线条，就考叠加 / 求同 / 求异
- 【翻译】三图叠加或求同：叠加（线条越来越多）；1. 去异求同（特殊：保留相同区域的面积） 2. 去异求同 + 旋转
- 【翻译】两图相同做求异：1. 去同求异 2. 去同求异 + 旋转
- 【翻译】邻图对比莫忘记：一次改变一点

## 第十五诀 有提示图形
- 【特征】由若干大的几何图形和若干小图形组成，小图形作为提示性标记，指示大图形中对应位置或属性
- 【口诀】提示图形先看数量
- 【口诀】多个提示图形看相互位置关系
- 【口诀】单个提示图形看所在位置特征
- 【翻译】提示图形先看数量：单纯数提示图形的数量
- 【翻译】多个提示图形看相互位置关系：相邻/间隔、点连/线连、平行/垂直
- 【翻译】单个提示图形看所在位置特征：1. 在边上/交点上，在大面/小面上 2. 在哪条边（长边/短边） 3. 在哪个角
- 【思路】⚠原文口诀列还有“图中有提示”几个字，可能是本诀口诀的开头，请核对

## 第十六诀 四个图形
- 【特征】每幅图由四个子图形组成
- 【口诀】子图形轮廓全部相同
- 【口诀】子图形部分相同（单图有相同图形）
- 【口诀】子图形部分相同（邻图有相同图形）
- 【口诀】子图形无规律
- 【翻译】子图形轮廓全部相同：1. 旋转 2. 样式交替/遍历（特征：都是相同的图形）
- 【翻译】子图形部分相同（单图有相同图形）：1. 种类数 2. 相同样式的位置关系——对角线、相邻
- 【翻译】子图形部分相同（邻图有相同图形）：邻图比较，邻图有相同子图形
- 【翻译】子图形无规律：1. 种类数 2. 子图形的图形特征——曲直性、开放封闭性

## 第十七诀 阴影
- 【特征】封闭区域内，大多只有一个阴影区域；无边框阴影
- 【口诀】阴影先看边与对称性
- 【口诀】再看外框与白块
- 【口诀】无格阴影看特征
- 【口诀】有格阴影看面积
- 【翻译】阴影先看边与对称性：阴影本身特征——1. 阴影边数（相同或递增） 2. 对称性
- 【翻译】再看外框与白块（阴影和其他图形的关系）：与外框相交——1. 相交的位置（上下左右） 2. 有几条黑边与外框相交（特征：阴影都在边边位置）；与其他白块相交——阴影都与白块相邻（特征：白块数量多）
- 【翻译】无格阴影看特征：面积（特征：外框是标准的几边形）；阴影与白块样式相同；一幅图/分类——1. 子图形特征：对称 2. 有共同子图形（黑白块）：位置 3. 面数、部分数；九宫格/两幅图——黑白运算（横看竖看）
- 【翻译】有格阴影看面积：面积（特征：区别黑白格，黑色连成一块）
- 【思路】⚠“面积（特征：外框是标准的几边形）”原文位置在“无格阴影看特征”附近，也可能属于“有格阴影看面积”，请核对

## 第十八诀 汉字
- 【特征】题目中的图形是汉字
- 【口诀】数面子图笔画数
- 【口诀】部分结构开闭性
- 【口诀】对称曲直横竖线
- 【口诀】脑洞题目很少见
- 【翻译】数面子图笔画数：面数量（特征：女、口、日、月、田）；相同子图形；笔画数——按汉字的写法数笔画（特征：丿、一、丨、日、口、心、贝、人、×）⚠这组“特征”放在笔画数下是推断的
- 【翻译】部分结构开闭性：部分数（特征：三点水、四点水、三撇、心）；结构——半包围、全包围、上下、左右；开放封闭性——有面就算封闭
- 【翻译】对称曲直横竖线：（特征：与其他非汉字图形混合考）1. 对称：口、日、中、田 2. 曲直性：有“丿”是曲 3. 横竖线：几横几竖
- 【翻译】脑洞题目很少见：考汉字本身含义的脑洞题很少，先按上面的属性做

## 第十九诀 标准黑白球黑白格
- 【特征】标准的黑白球或黑白格（3×3 / 4×4）
- 【口诀】先验对称数部分
- 【口诀】球数不同算黑白
- 【口诀】球数相同考平移
- 【口诀】3个以内分别看
- 【口诀】内圈外圈要先验
- 【口诀】每行每列分别数
- 【口诀】全同换行分清楚
- 【翻译】先验对称数部分：对称——黑色/白色整体对称；部分——黑白部分数、黑白球的数量及分布（顺便看看一笔画；特征：黑色/白色连成一片、一条线，多是 5×5 图）
- 【翻译】球数不同算黑白：黑白运算——九宫格、两幅图
- 【翻译】球数相同考平移：1. 球数相同 2. 球数相同 + 平移
- 【翻译】3个以内分别看：3×3 / 3 个黑球以内——位置不变是平移，少一个球是重叠
- 【翻译】内圈外圈要先验：内外圈分别平移（特征：4×4 / 5×5，内外圈数量一致）
- 【翻译】每行每列分别数：每行/列数量一致——整行/列移动
- 【翻译】全同换行分清楚：行/列数量不完全对应——移动两次

## 第二十诀 非标准黑白球黑白格
- 【特征】非标准的黑白球或黑白格（如类圆圈图形）
- 【口诀】先验对称数部分
- 【口诀】球数不同算黑白
- 【口诀】球数相同考平移
- 【口诀】3个以内分别看
- 【口诀】内圈外圈要先验
- 【口诀】每行每列分别数
- 【翻译】前几句同第十九诀：对称——黑色/白色整体对称；部分——黑白部分数、数量及分布；球数不同做黑白运算（九宫格、两幅图）；球数相同考平移；3×3 / 3 个黑球以内位置不变是平移、少一个球是重叠；每行/列数量一致就整行/列移动
- 【翻译】内圈外圈要先验：内外圈分别平移（特征：类圆圈图形，内外圈数量一致）
- 【翻译】与标准黑白球的不同点：一笔画的图形特征；整图旋转；两类黑白球连线；特殊图形——看特殊图形找规律（特征：多是分类题目或一组图）

## 第二十一诀 连线图形
- 【特征】图形由球（点）和连线组成
- 【口诀】连线不交，看连线
- 【口诀】相交，看交点
- 【翻译】连线不交，看连线：连接图形特征——1. 相同图形，连接的是什么图形 2. 找特殊图形（连线最多的）
- 【翻译】相交，看交点：部分数；球数量——1. 线穿过球的数量 2. 未穿过（白色）球的数量分布；交点位置——交点在球上、交点在空隙上
- 【翻译】非典型：全图覆盖
- 【思路】⚠原文口诀列只识别出“连线不交,看连线相交,看”，第二句的最后一个字缺失，“相交，看交点”是按下文补的，请核对

## 第二十二诀 抽象生活图形
- 【特征】图形是抽象化的生活物品
- 【口诀】生活图形贼抽象
- 【口诀】对称部分面数量
- 【口诀】开闭曲直子图形
- 【翻译】生活图形贼抽象：别被样子迷惑，照常找属性规律
- 【翻译】对称部分面数量：对称；部分数；数面——数黑色阴影部分的面数
- 【翻译】开闭曲直子图形：开放封闭性（有线头漏出就算开放）；曲直——曲直性、曲直数量；子图形

## 第二十三诀 英文字母或数字
- 【特征】图形是英文字母或数字（常与其他图形混合考）
- 【口诀】对称数面曲直开闭
- 【口诀】交点笔画数
- 【翻译】对称数面曲直开闭：对称——轴对称、中心对称、对称轴方向、对称轴过线/点/面；数面；曲直——纯直、纯曲、曲+直；开放封闭性
- 【翻译】交点笔画数：交点数；笔画数（与其他图形混合考）
- 【翻译】非典型：字母顺序；平行线；数字/字母遍历

## 第二十四诀 平面拼合
- 【特征】题目给出几个图形，问哪个选项能由它们拼成（只能平移，不能旋转）
- 【口诀】拼合关键三要素
- 【口诀】非典型秒杀思维
- 【口诀】五大秒杀定理
- 【翻译】拼合：优先思考哪些选项的外框不可能由题目中的图形拼成
- 【翻译】拼合关键三要素（只能平移，不能旋转）：(1) 只能上下左右移动，能拼合的两条线必须平行；(2) 分别是图左线和图右线，或者图上线和图下线；(3) 两条线等长且满足 (1)(2)，拼合后会消失（不体现在外框）；不等长时，差值要么被另一条平行线抵消，要么在外框体现
- 【翻译】五大秒杀定理：(1) 某条线没有与之平行的图上线/图下线时，它必须出现在外框的上方/下方；(2) 平行的线都在图的同一侧时，需要叠加或两条都独立存在；(3) 题目中没有某角度的线，选项中也不能出现；(4) 等长的平行线有多条时两两抵消，余下的必须出现在外框；(5) 平行线不等长时，一根长线可以被两根短线拼合后抵消
- 【翻译】技巧：先找最长的横线或竖线，再看最长的斜线，然后找与之平行、可以抵消的线
