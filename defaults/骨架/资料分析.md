# 资料分析 · 功法（题型识别 + 公式速算）

> 审改说明：一个 `## 标题` = 一种题型（一重功法）。每种题型练两件事：
> - `【识别】`：看到题干的哪些信号就知道是这个题型（时间、主体、关键词、选项形式）——说出大意即可；
> - `【公式】` / `【速算】`：这个题型的公式和简便算法——说出大意即可（字母写法不限，意思对就行）；
> - `【口诀】`：必须一字不差（只有少数几句）；`【术语】`：要说全，但允许同义表达。
> - `> 真题例：` 开头的行是原资料里的真题题干，只作参考、出题素材，不参与默写判分。
> 字母约定：现期 A、基期 B、增长率 r；部分增速 a、整体增速 b（分子增速 a、分母增速 b）。

## 做题总纲（3+2）
- 【口诀】圈时间、判题型、定主体
- 【思路】圈时间：先看问的是哪一年/哪个时段——问的时间在材料时间之前就是基期类，和材料同时间就是现期类，两个时间就是“两期”类
- 【思路】判题型：看问法（求量？求增速？求比重？求倍数？求平均？比较？）再对照材料给了什么
- 【思路】定主体：找准讨论对象，检查每个数字前面的主体是不是所需对象（全国/某省、限额以上/全部、当月/累计）
- 【思路】做题步骤：读题 → 锁定关键时间 → 扫读选项看精度差距 → 在材料里找数据核对主体 → 列式速算，注意单位换算和数据范围

## 基期量
- 【识别】问的是“基期时间 + 主体”（问的年份早于材料年份），材料给了现期量和增长率（“同比增长 x%”“下降 x%”）
- 【识别】问“基期 = ?”而材料写的是“增长了多少（增量）”时，是加减计算的基期
- 【公式】基期 = 现期 ÷ (1 + r)；给了增量时，基期 = 现期 − 增量
- 【速算】截位直除；|r| ≤ 10% 时化除为乘：基期 ≈ 现期 × (1 − r)（下降时 ≈ 现期 × (1 + |r|)）
- 【速算】r 接近常用百分数时用分数法：r = 1/n，基期 = 现期 × n/(n+1)
- 【速算】给增量做减法时用划线法、尾数法；还可以代入选项、假设法
> 真题例：2022年3月，新疆外贸出口值约为？（同比增长78.9%）
> 真题例：2019年，H省秋粮稻谷的平均生产成本约为多少元/亩？（下降4.0%）
> 真题例：本年度上半年，煤炭进口量约为多少万吨？（给了增量 → 加减计算）

## 基期和差
- 【识别】基期时间 + “A 比 B 多/少多少”（基期差）或“A 与 B 共/合计多少”（基期和）
- 【识别】隐性的和：所求整体在材料里是两部分给的，例如彩票销售额 = 福利彩票 + 体育彩票
- 【公式】基期差 = A/(1+a) − B/(1+b)；基期和 = A/(1+a) + B/(1+b)
- 【速算】两部分分别化除为乘或截位直除后再加减；选项形式为“少 X、多 X”时先判断方向
> 真题例：2018年1月，我国摩托车产量比销量？（选项形式为少X，多X）
> 真题例：2021年上半年全国彩票销售额约为多少亿元？

## 现期量（求整体 / 求现期）
- 【识别】问的时间和材料相同，求某个量；只看题干和“求部分”一样，要结合材料判断
- 【识别】材料给的是部分值 + 比重 → 求整体；给的是整体 + 比重 → 求部分
- 【公式】整体 = 部分 ÷ 比重；部分 = 整体 × 比重；现期 = 基期 × (1 + r) = 基期 + 增量
- 【速算】除以比重用截位直除；乘法用放缩 A × B ≈ (A − Ar) × (B + Br) 把一个数凑整
> 真题例：2023年，全国技工院校在校生人数？（材料给部分值 + 比重）
> 真题例：2022年东部地区完成互联网业务收入为？（材料给整体值 + 比重）

## 保持增长量（年增量不变、追赶）
- 【识别】“如保持某年同比增量不变”“年增量保持不变” + “首次超过某个数”“哪一年超过”“差值是多少”
- 【识别】追赶问题：两个主体各自按固定增量增长，问 A 何时第一次超过 B、或到某年 A 与 B 差多少
- 【公式】n 年后现期 = 现期 + n × 年增量；追上所需年数 = 当前差距 ÷ 每年增量之差
- 【速算】累计相加，直到符合要求；追赶只算差距和增量差，不必算两个主体各自的值
> 真题例：如从2016年开始，社会消费品零售总额年增量保持不变，社会消费品零售总额首次超过40万亿元的年份是
> 真题例：如保持2021年同比增量不变，则到哪一年第三方互联网超算服务商提供的服务市场规模将第一次超过第三方独立超算服务商？

## 保持增长率（按某增速推算）
- 【识别】“若按照某年同比增长率”“按某增速推算”“每年均按某时段平均增速增长” + 求某年的现期
- 【公式】n 年后 = 现期 × (1 + r)^n；按平均增速时先求平均增速：(末期/初期) 开 n 次方 − 1
- 【速算】(1 + r)^n ≈ 1 + nr + n(n−1)/2 × r²（r 较小时取前两三项即可） ⚠ 这条速算是补充的，原资料没写
> 真题例：如按2021年我国农作物种子出口量同比增速推算，2022年我国农作物种子出口量约为多少万吨？
> 真题例：若从2023年起，每年均按2018-2022年的平均增速增长，则2027年城镇职工基本医疗保险参保人数将达到（）

## 增长量
- 【识别】“比上年增加/增长了多少 + 单位（亿元、万吨）”；材料给了现期量、增长率
- 【公式】增长量 = 现期 − 基期 = 基期 × r = 现期 × r/(1 + r)
- 【速算】分数思想：r = 1/n 时，增长量 = 现期 ÷ (n + 1)；下降 1/n 时，减少量 = 现期 ÷ (n − 1) ⚠ 原笔记写“增长量 = 现期/(m+n)”，只在分子为 1 时成立；一般 r = n/m 时增长量 = 现期 × n/(m+n)
- 【速算】r 不正好是常用百分数时修正：实际 r 比所取分数大，增量就比算出来的大，按 (实际 r − 所取 r)/所取 r 的比例上调
- 【速算】|r| ≤ 10% 时化除为乘：增长量 ≈ 现期 × r，结果偏大，可对增量再化除为乘一次纠偏（增量 − 增量 × r）
> 真题例：2019年A市专利密集型产业实现增加值比上年约增长多少亿元？
> 真题例：2022年1~7月份，全国城乡居民生活用电量比2021年1~7月份约多？（12.5%）

## 重要百分数（分数思想用）
- 【术语】1/2 = 50%，1/3 ≈ 33.3%，1/4 = 25%，1/5 = 20%，1/6 ≈ 16.7%
- 【术语】1/7 ≈ 14.3%，1/8 = 12.5%，1/9 ≈ 11.1%，1/10 = 10%，1/11 ≈ 9.1%
- 【术语】2/7 ≈ 28.6%，2/9 ≈ 22.2%，3/7 ≈ 42.9%
- 【术语】2/3 ≈ 66.7%，3/4 = 75%，4/5 = 80%，5/6 ≈ 83.3%
- 【思路】用法：增长率接近哪个百分数，就换成对应分数，把“除以 1+r”变成“除以 n+1”

## 年均增长量 / 月均量
- 【识别】“年均增长多少 + 单位”→ 年均增长量；“平均每月”“月均” + 时间段 → 时间平均数
- 【公式】年均增长量 = (末期 − 初期) ÷ 年份差（间隔年数，不是年份个数）
- 【公式】月均量 = 这段时间的总量 ÷ 月数；比较“12月”和“1-11月月均”时，1-11月要先除以 11
- 【易错】数年份差：2018→2022 是 4 年；五年计划如“十四五”= 2021-2025 年
> 真题例：2022年1-4月，福利彩票平均每月销售额约为多少亿元？

## 一般增长率
- 【识别】“同比增长了百分之几”“比上年增长约？”，选项是百分数
- 【公式】增长率 = 增量 ÷ 基期 = (现期 − 基期) ÷ 基期 = 现期/基期 − 1
- 【速算】给了现期和增量时：r = 增量 ÷ (现期 − 增量)；截位直除，看选项差距定精度
- 【易错】“提高了 x 个百分点”是比率的增量（做减法），不是增长率

## 隔年增长率
- 【识别】比较的两个时间相差两年（例如 2022 年与 2020 年相比），材料给了今年增速 r1 和去年增速 r2
- 【公式】隔年增长率 = r1 + r2 + r1 × r2
- 【公式】变形：隔年倍数 = 1 + 隔年增长率；已知隔年增速反求：r1 = (r0 − r2)/(1 + r2)
- 【速算】r1 × r2 很小时估一下量级即可；百分数相乘时 r1 × r2 / 100（例如 10% 和 20% → 10 + 20 + 2 = 32%）
> 真题例：2022年全国银行机构和理财公司累计新发理财产品只数与2020年相比约？
> 真题例：2023年2月，全国旅游客车销量约是2021年2月的（）倍？

## 乘积增长率
- 【识别】材料里存在 A = B × C 的等量关系，所求量是乘积：总产量 = 面积 × 亩产、销售额 = 单价 × 销售量、同城快递业务量 = 全国快递业务量 × 同城占比、城镇人口 = 常住人口 × 城镇化率
- 【公式】r_A = r_B + r_C + r_B × r_C
- 【速算】步骤：① 增速相加 ② 加上两增速之积（百分数相乘再除以 100）
- 【思路】比重的增速要先用“增量 ÷ 基期”估出来（例如城镇化率提高 0.36 个百分点，增速 ≈ 0.36/62.12 ≈ 0.58%），再和部分、整体的增速“知二求一”
> 真题例：同城快递业务量增速：全国快递业务量同比下降 0.9%，同城占比 11.7%、比上年下降 1.4 个百分点，求同城业务量同比增速

## 平均数增长率（除法增长率）
- 【识别】所求量是除法关系：平均数、人均、单价、亩产、利润率等“A/B”型指标 + “比上年增长？”，选项是百分数
- 【识别】材料存在 A = B ÷ C，例如一般公共预算收入 = 税收收入 ÷ 税收占比
- 【公式】平均数增长率 = (a − b) ÷ (1 + b)（a 分子增速，b 分母增速）
- 【速算】步骤：① 增速差 ② 除以 (1 + b)；除以 1 + b 可以再化除为乘
- 【思路】均值变化方向：a > b 均值变大，a = b 不变，a < b 变小（1 + b 恒为正）
> 真题例：2018年中国平均每块集成电路出口单价比上年？（选项都是增长率）

## 平均数（现期 / 基期 / 增长量）
- 【识别】“平均每 X 的 Y”“人均”“单产”“均价”；现期时间 → 现期平均数，基期时间 → 基期平均数
- 【识别】“平均数 + 增量/比上年增加多少元”，一般要从选项看出问的是平均数的增长量
- 【公式】现期平均数 = A ÷ B；基期平均数 = A/B × (1 + b)/(1 + a)
- 【公式】平均数增长量 = A/B × (a − b)/(1 + a)
- 【速算】P神：问去求今——先算现期平均数，再用平均数增长率算基期或增量
- 【思路】基期比问题（例如给产量、面积的现期和增速，求去年亩产）：思路一，分别算产量、面积的基期再相除；思路二，先求现期亩产，再用平均数增长率反推基期和增量
> 真题例：2023年二季度末，全国跨省联网异地就医费用直接结算减少个人垫付次均金额环比有所增加的是？
> 真题例：2019年棉花种植面积排名前7的省区中，棉花单产超过1吨/公顷的省区有几个？

## 现期比重
- 【识别】一个时间 + “占 / 是” + 两个主体（部分和整体），时间与材料相同
- 【公式】比重 = 部分 ÷ 整体 × 100%
- 【速算】截位直除；选项差距大时只看首两位
> 真题例：2023年广东高技能人才占全省技能人才总量的
> 真题例：已知2022年1~11月我国高新技术产品进出口总额约为14544亿美元，则同期我国工业机器人设备累计进出口总额约占高新技术产品累计进出口总额的？

## 基期比重
- 【识别】和现期比重一样是“占 / 是 + 两个主体”，但问的时间是基期（材料之前）
- 【公式】基期比重 = A/B × (1 + b)/(1 + a)（A 部分现期，B 整体现期；a 部分增速，b 整体增速）
- 【速算】先算现期比重 A/B，再乘 (1 + b)/(1 + a)，这个因子接近 1 时化除为乘
- 【速算】P神：问去求今，现期比重 − 比重变化量（两期比重差）
> 真题例：2021年农村公路交通固定投资额占公路交通固定投资额的比重为？

## 两期比重差（比重增量）
- 【识别】两个时间 + “占 / 是” + 两个主体，问“比上年上升/下降了几个百分点”
- 【识别】自带比重含义的词 + 两个时间：产销率、营业利润率、人口城镇化率、利润率（这些本身就是比重）
- 【公式】两期比重差 = A/B × (a − b)/(1 + a)（a 部分增速，b 整体增速）
- 【速算】三步走：① 增长率差 (a − b) 定方向 ② 乘现期比重 A/B ③ 除以 (1 + a)
- 【思路】方向：部分增速 a > 整体增速 b 比重上升，a = b 不变，a < b 下降；结果的绝对值小于 |a − b|
- 【思路】没有增速、只给了现期和基期（或增量）时：直接算现期比重和基期比重再做差
> 真题例：2022年1-12月，全国旅游客车产销率相较于2021年同期增加的月份有几个？
> 真题例：相比2019年，2020年我国民航全行业完成旅客运输中，国内航线完成旅客运输总量占比约？

## 现期比重差（同期两个比重）
- 【识别】一个时间 + “比” + 两个比重（第二个“比重”常被省略），例如“0~4岁组占比比25~59岁组高多少个百分点”
- 【公式】比重差 = A1/B − A2/B = (A1 − A2)/B（同一整体时直接先减后除）
- 【速算】尽量化成同一个分母；不能化同分母就分步除
> 真题例：H市2023年第14周哨点医院报告流感样病例中0~4岁组占比比25~59岁组高约多少个百分点？

## 比重比较与类比
- 【识别】比重 + 具体值：“占比超过 10% 的指标有几个”“最接近 25% 的是”
- 【识别】比重 + 大小比较：“占比最高的年份”“比重大约是”（材料里有其他相关比重可以类比）
- 【速算】和具体值比较：把比重换成“部分 vs 整体 × 具体值”比较，免去除法
- 【速算】类比：插入 1.1、1.2、1.5 这类倍数值，判断与倍数值的方向
- 【思路】A = B + C 型（常住人口 = 城镇 + 农村）：比较 B/A 的大小，等价于比较 B/C 的大小
> 真题例：2018-2022年，行政案件在G省法律援助案件中占比最高的年份是？
> 真题例：2020年，我国网上销售额占社会消费品零售总额比重大约是？

## 倍数
- 【识别】“A 是 B 的多少倍”→ 现期倍数；问的是过去时间 → 基期倍数；“A 比 B 多 () 倍”= 倍数 − 1
- 【识别】定位 + 现期倍数：先按条件定位某年/某行业，再求倍数（例如“平均工资最高的行业，其 X 是 Y 的多少倍”）
- 【公式】现期倍数 = A ÷ B；基期倍数 = A/B × (1 + b)/(1 + a)
- 【速算】截位直除；判断“超过 3 倍”时直接比较 A 和 3B，不必做除法
> 真题例：2021年上半年，我国原油进口量比生产量多（）倍
> 真题例：2013-2022年，全国亿元以上食品饮料市场成交额超过烟酒市场3倍以上的年份有？

## 混合增长率（整体 = 部分之和）
- 【识别】整体由两部分组成，给了两部分增速求整体增速，或给整体和一部分反求另一部分
- 【识别】常见组合：1-8月 = 1-7月 + 8月；出口 = 顺差 + 进口；进口 = 逆差 + 出口；餐饮收入 = 限额以上 + 限额以下；城乡、男女、本硕人数
- 【公式】定性：整体增速在两部分增速之间，且更靠近基期量大的那部分
- 【公式】定量：两部分增速到整体增速的距离之比 = 两部分基期量的反比（十字交叉）
- 【速算】步骤：① 按基期大小判断偏向，排除“半区”外的选项 ② 估算倍数 ③ 总距离 ÷ (倍数 + 1) ④ 从离得近的增速加/减上一步结果
- 【思路】月累计：当月同比增速 > 累计同比增速 ⇔ 累计同比增速比上期累计上升；当月 < 累计 ⇔ 累计增速下降
> 真题例：2021年1~2月，限额以下单位餐饮收入同比约增长了？（材料信息：餐饮收入、限额以上餐饮收入）
> 真题例：2020年3-12月，J省当月发电量同比增速快于当月累计发电量同比增速的月份有几个？（材料信息：1-2月，1-3月，1-4月）

## 增长量大小比较
- 【识别】“增量最大/最多的是”“同比增量最大的年份”
- 【公式】增长量 = 现期 × r/(1 + r)
- 【速算】两个增速相差不大时，直接比较 现期 × r；增速差得大时再用 (1 + r) 微调；差得非常大就老实算出来
- 【速算】大大则大：现期大、增速也大，增量一定大
> 真题例：2012~2020年，中国IC封装市场规模同比增量最大的年份是
> 真题例：2021年1~2月，以下各类社会消费品零售总额中同比增量最大的是

## 增长率大小比较 / 特定增长率
- 【识别】“增长最快/最慢”“增速超过 20% 的年份有几个”“环比增速大于 10% 的月份有几个”
- 【公式】增长率比较时，比较 增量/现期 和比较 增量/基期 结论一致，不必算基期
- 【速算】特定增长率：给了现期和基期时，r > 10% ⇔ 现期 > 基期 × 1.1；20%、50% 同理（1.2、1.5），5%、15% 类推
- 【速算】给了现期和基期（连续年份表）时，直接看 现期/基期 的大小，差不多时再用差分法
> 真题例：2019-2022年全国体育场地面积增长最快的年份是？
> 真题例：2022年4~10月，H国发电量环比增速大于10%的月份有几个？

## 分式大小比较
- 【识别】比较两个或多个 A/B 型数值（比重、平均数、倍数）的大小，“谁高谁低”“最高的是”
- 【速算】直除：分母差不多时直接估算首位
- 【速算】差分法：a/A 与 b/B 比较，算 (a − b)/(A − B)，它和 b/B 比大小，a/A 就在两者之间
- 【速算】代入法：先算出一个比较好算的 m = a/A，再看 B × m 与 b 的大小
- 【速算】基准比较：两个分数都接近某个常用值（0.1、0.5、1）时，看各自离基准的距离

## 除法速算（化除为乘、放缩）
- 【公式】|r| ≤ 10% 时：A/(1 + r) ≈ A × (1 − r)；A/(1 − r) ≈ A × (1 + r)
- 【速算】化除为乘有误差：结果偏大/偏小时可以“二次化除为乘”修正；增速本身也可以先化除为乘再用
- 【速算】等比例放缩：分子分母同乘同一个数，把分母凑成整数（例如 422/191 ≈ 440/200 的思路：分母加 9，分子按比例加约 2×9）
- 【速算】放缩两种思想：减少位数（1.91 → 2.00）、凑百化分（1.23 → 1.25 = 5/4）
- 【速算】乘法放缩：A × B ≈ (A − Ar) × (B + Br)，一个数凑整、另一个反向调整同样的比例

## 拉动增长与贡献率
- 【识别】“拉动某整体增长多少个百分点”→ 拉动增长；“对整体增长的贡献率”→ 增长贡献率
- 【公式】拉动增长 = 部分增量 ÷ 整体基期 × 100%
- 【公式】增长贡献率 = 部分增量 ÷ 整体增量 × 100%
- 【易错】拉动增长的分母是整体的基期，不是整体的增量

## 容斥（关联问题）
- 【识别】问卷多选（78 人选 A、64 人选 B）、企业分类（54 家国有、71 家本地），问“至少/至多有多少同时满足”
- 【公式】A ∩ B = A + B − A ∪ B
- 【思路】A ∪ B 的范围是 [A、B 中的较大值, 全集]，所以 A ∩ B 的范围是 [A + B − 全集, A、B 中的较小值]；只要 A + B > 全集就一定有交叉

## 易混概念
- 【思路】现期、基期：前后对比中靠后、靠前的时间点；增量是从基期到现期增长了多少
- 【思路】同比是和上一年同期比，环比是和上一个统计周期（上月、上季度）比
- 【思路】顺差 = 出口 − 进口（出口大时），逆差 = 进口 − 出口；进出口总额 = 进口 + 出口
- 【思路】行业增加值是该行业在该时期创造的产值，是现期量，不是增长量
- 【思路】周转量 = 运输量 × 运输距离
- 【思路】实际增长率是扣除价格因素后的增长率；CPI/100 = 1 + 居民消费价格同比涨幅
- 【思路】“增长 x%”是增长率；“提高 x 个百分点”是两个比率直接相减
