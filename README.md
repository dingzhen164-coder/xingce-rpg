# 行测修仙传（行测 RPG）

把行测复习做成一个修仙游戏的本地网页：用**费曼学习法 + 系统默写**把每个板块的“功法”（知识骨架）练到一个不漏说出来。
修为推动道行（预估分 50 → 80+），道行决定境界——凡人、炼气一至九层、筑基、金丹、元婴、化神、大乘、真仙；
突破大境界要**渡劫**，而且最近两次**宗门大比**（模考）都得达线。每个板块是一条**灵根**（天地玄黄八品，会跌落），
落后了去**丹房炼丹**加练，还有闭关、顿悟、走火入魔、道心、宗门周常、储物袋、飞升记录。
导师是接入 AI 的傲娇女仙师尊**劭神韵**，会结合你的实际进度现场说话。设置里可以一键切换成**西方玄幻风格**（导师艾琳学姐）。

- 只在自己电脑上运行（浏览器打开 `127.0.0.1`），数据放在 Obsidian 行测库的 `训练/` 文件夹，坚果云自动同步到另一台电脑；
- 只需要电脑上有 Python（Windows / Mac 都行），**不用安装任何别的东西**；
- AI（判默写、论道追问、判错题、生成功法、师尊说话和聊天）用你自己的 DeepSeek API key。

> 给其他 AI / 开发者：先读 [AGENTS.md](AGENTS.md) 和 [DESIGN.md](DESIGN.md)。

## 一、安装（只需在一台电脑上做一次）

1. 在 GitHub 仓库页面点 **Code → Download ZIP**，解压。
2. 在 Obsidian 行测库里新建文件夹 `训练/程序/`，把解压出来的**所有文件**复制进去。
   最后应该是：`行测/训练/程序/server.py`、`行测/训练/程序/rpg/`、`行测/训练/程序/web/` ……
   （放在库里，坚果云会同步到另一台电脑，两台都不用再装。）
3. 启动：
   - **Windows**：双击 `训练/程序/启动训练.bat`
   - **Mac**：双击 `训练/程序/启动训练.command`（第一次如果提示“无法打开”：右键 → 打开；
     或者在终端运行 `python3 "<库路径>/训练/程序/server.py"`）
4. 浏览器会自动打开训练页。第一次运行会在 `训练/` 里生成 `规则.md`、`角色设定.md`、`台词库.md`。
5. 点右上角 **设置**，填 DeepSeek 的 API key，点“测试 AI 连接”。
   **key 只保存在这台电脑**（`~/.xingce-rpg/settings.json`），另一台电脑要再填一次。

关掉黑色的终端窗口 = 关掉程序。

## 二、更新

重新 Download ZIP，把文件**覆盖**复制到 `训练/程序/`。你的数据在 `训练/` 下的其他文件夹里，不受影响。

程序升级如果改了配置文件的结构，会自动把你的 `规则.md` / `角色设定.md` / `台词库.md` 备份成 `xxx.旧版.md`
再换成新版（网页顶部会提示）。你改过的内容可以从旧版里抄回来。

## 三、怎么修炼

1. **藏经阁**：给当前秘境的板块点“编撰功法” → AI 从你的解题 skill 里提炼草稿 → 到 Obsidian 里审改
   `训练/骨架/<板块>.md` → 回网页点“定稿”。
2. **洞府**的“今日功课”每天自动生成：渡劫（条件满足时）→ 疗伤 → 温养道基 → 斩心魔 → 新修（背诵口诀 / 论道 / 试剑）。点一项就开始。
3. 每一重功法：背诵口诀连续过 2 次（小成）→ 论道过 1 次（大成）→ 试剑连续过 2 次（圆满），之后按 3/7/15/30/60 天温养。
4. 一个板块全部圆满 → 觉醒对应**灵根**；灵根品阶按该板块模考正确率算（天阶上品 ≥90%，常识 ≥80%），越熟的板块修为加成越高、温养间隔越长。
5. 每次模考出分后到**修仙录**记录宗门大比：最近两次的较低分若高于当前道行，修为直接补上（可以直接跨好几层）。
6. 修为到了 60 / 65 / 70 / 75 / 80 / 85 分线会进入**瓶颈**：最近两次大比达线 + 灵根达标 + 道心 ≥60 → 首页出现“渡劫”，
   连续扛过几道天雷才能突破；失败会道基受损，冷却 3 天并先疗伤。
7. 落后天道进度时去**丹房**炼丹（加练一炉，按成功率成丹、额外修为）；想专注一个板块就**闭关**。
8. 有事修炼不了：修仙录里用**告假玉简**（每月 4 份）。累了直接在对话框说“好累”，师尊会先安慰你。
9. 营地 / 洞府点“向师尊请教”：问方法、让她帮你分析现状排计划，她看得到你的全部进度。

## 四、改规则 / 人设 / 台词（不用改代码）

在 Obsidian 里改这些文件，保存后**刷新网页**就生效：

| 文件 | 改什么 |
|---|---|
| `训练/规则.md` | 目标日、境界分数线、渡劫条件与天雷数、灵根门槛与加成、丹药 / 闭关 / 顿悟 / 走火入魔、周常、分批、修为值…… |
| `训练/角色设定.md` | ID、头像（放进 `训练/`）；修仙 / 玄幻两种风格各自的称呼、导师名 / 头像 / 人设、吐槽尺度 |
| `训练/台词库.md`、`训练/台词库·玄幻.md` | 两位导师的备用台词（没连 AI 时用），随便加 |
| `训练/骨架/<板块>.md` | 功法（默写标准）：`## 大项`、`- 【术语】名称：解释`（完整清单，允许同义表达）、`- 【思路】……`（说大意） |

想加新功能、改界面：把这个仓库交给 AI，让它先读 `AGENTS.md`。

## 五、常见问题

- **修炼时间怎么算**：只有打开一项功课（背诵、论道、试剑、斩心魔、渡劫、炼丹……）并且在操作时才计时，做完看解析的 3 分钟也算；
  只是开着网页、看面板、和师尊闲聊不算。顶栏的计时器在计时时会亮起闪烁。线下做题的时间到“修仙录 → 历练”手动补录。

- **打不开 / 闪退**：用终端运行 `python server.py`（Mac 用 `python3`）看报错。需要 Python 3.8 以上。
- **提示另一台电脑在用**：两台电脑同时开会让坚果云同步冲突，先关掉另一台上的程序（10 分钟后提示自动消失）。
- **提示有冲突副本**：`训练/存档/` 里出现带“冲突”的文件，说明两台同时写过。保留较新的那份，另一份删掉。
  每天第一次保存前都会自动备份到 `训练/存档/备份/`（保留 14 天）。
- **图形推理**：程序自带薛睿图推 24 诀功法（`训练/骨架/图形推理.md`），每一诀练三件事——适用图形的特征、口诀原句（一字不差）、口诀翻译。
  第一次运行会复制成草稿，对照原资料核对完标 ⚠ 的地方再定稿。
- **资料分析**：程序自带“题型识别 + 公式速算”功法（`训练/骨架/资料分析.md`，第 3 批），一个 `##` = 一种题型，每种练两件事——
  【识别】看到题干哪些信号就知道是这个题型；【公式】/【速算】这个题型的公式和简便算法。`> 真题例：` 行是原资料的真题题干，不判分。
  试剑是“识别速答”：师尊只出一句题干，你说出题型、识别依据、公式、速算方法，不用算数。
  如果库里已经有按 skill 生成的 `资料分析.md`，不会被覆盖，程序自带那份会放在旁边叫 `资料分析.程序自带版.md`，想用就改名替换。
- **常识**：目前是“副线”，只统计模考实战正确率；常识知识库、错题自动归档在第二版（见 DESIGN.md 路线图）。


## 六、顺序真题实战

启动时自动创建 `训练/题库/`，包含现有 12 个板块的空白真题 Markdown 模板。
打开如 `论证逻辑真题.md`，将代码块内示例复制到代码块外，替换为你的真题。
每题用 `## 题目 固定编号`，包含 `### 知识点`、`### 题干`、`### 选项`、`### 答案`、`### 解析`；
选项是 A/B/C/D 单选，答案小节只写一个字母。每个板块内编号唯一、固定，程序按文档出现顺序做题，不按编号大小排序。
材料题将共同材料复制到各子题题干。

**批量入库**：试炼塔页面的「📥 导入真题」，不用 AI 逐题核对、几秒钟入库：
- **模考**：在「① 模考」点「选择文件」选粉笔模考 PDF，点「拆分并导入」——程序自动存进 `FB模考试卷复盘/模考试卷/`、调用 xingce-mokao-split 拆成板块复盘（和以前做复盘一样），再导入试炼塔。不用记命令。文件名没有“第X季”时填一下第几季。第一次用要点「安装拆分组件」（pymupdf，只装一次）。已经拆好的季在下面列出，点「导入」。题干、选项、答案、截图都来自 PDF 原文，
  来源自动写“（粉笔第36季模考）”，截图复制到 `训练/题库/图片/<板块>/`。导过的题再点也不会重复。
- **txt**：练习册、真题卷的 OCR 文字。选文件，填编号前缀（如“四海逻辑600”），来源能认出就自动写，练习册勾“没有来源”。
- **PDF（有文字层）**：WPS / Word 导出的、或 OCR 软件生成的“可搜索 PDF”，在同一处直接选。比转 txt 多保住逻辑填空的横线（写成 `____`）和双空选项之间的空格。“拔高刷题十一”“练习题16”这类标记按里面的数字分套。扫描图片 PDF 没有文字层，要先 OCR 成可搜索 PDF。需要 pymupdf（① 里的“安装拆分组件”）。
  能干净拆开的题直接入库，拆不干净的放进 `训练/题库/_待修/<名称>.md`：在 Obsidian 里改好、清空那道题的“### 检查”，回来点「重新导入」；修不了就删掉。
  粉笔试卷的 OCR 文字顺序会乱，请改用上面的“模考”方式。
- **补答案**：练习册答案在另一本时。整本一次补：前缀填导入时的前缀（如“花生600题”），答案每行一套“练习01 ADDBA CDCAB DBBCC BBADD”；
  只补一套：前缀写到第几套（如“花生600题-03”），答案写“1-5 ABCDA”或“1.A 2.B”。练习册按每套开头的“练习题NN”分套，套号和答案表对得上。
- **撤销一批**：导错了想重导时，填编号前缀删除这批还没做过的题（做过的有作答记录，保留）。
- **知识点**：按问法自动猜（削弱、加强、真假推理……），猜不出写“待分类”，不影响做题；设置了 DeepSeek 可以点「AI 补 100 题」，
  只发题干给 AI（有骨架的板块用骨架的大项名），几百道题几毛钱。
- 想让 AI 精修个别题时，还可以用 obsidian-to-xingce 仓库的 `xingce-tiku` skill（费 token，一般用不到）。
- **图**：图形推理、资料分析的图放在 `训练/题库/图片/<板块>/`，题干里写 `![[训练/题库/图片/图形推理/编号.png]]`，试炼时会显示图片。
- **答案待补**：`### 答案` 写“（待补）”的题先不出，题库页显示“待补答案 N 道”。
- **解析待补**：`### 解析` 可以写“（待补）”，作答后显示“解析待补”，之后再用 skill 补。

在 **试炼塔** 选择每组 10 或 15 道；当天有骨架训练的板块会在最后一项知识训练后插入实战功课。
也可以直接从实战题库开始。剩余不足一组时做完剩余题，题库做完后等待你添加新题，不自动循环。

**交卷式试炼**：点选项作答的组（板块组、整套试炼、错题复练）全部选完点「交卷」才判分：可以翻回去改答案，答题时不显示对错。
交卷后给正确率、品评、答题卡，师尊按成绩调侃一句，然后逐题复盘（题干、你的答案、正确答案、解析），可跳“下一道错题”。
「🧙 师傅解惑」把这道题和所属板块的 skill（常识判断用 xingce-changshi）发给 AI，按功法讲题并带人设调侃，同一题讲过的会留着；
没连 AI 时只说一句台词。复盘中途可“稍后再看”，再进来还在复盘。写拆题过程的论证逻辑组仍一题一判（要逐题审方法）。
计时：每道题从显示到离开记一次（翻回来改答案的时间也算这道题，单次最多记 10 分钟，暂离不计），战斗面板实时走秒；
交卷后给成绩表（题、编号、板块、知识点、我选、答案、对错、用时，跨板块再按板块汇总），结束复盘时再给一次，
并追加到 `训练/试炼记录/<日期>.md`；试炼战绩里显示每组用时。
新台词场景：试炼·没做完 / 全对 / 上品 / 中品 / 下品 / 复盘错题 / 复盘结束 / 解惑没AI；自己的台词库里没有的场景自动用默认台词。

**修炼殿**（导航“修炼”）是主入口，两扇门：「修炼」自选板块（红色印章）→ 每个大项一张卡，直接点背诵口诀 / 论道 / 化法为境 / 试剑，
今日该温习的大项标橙；板块上还有「斩心魔」（自动挑这个板块最该斩的模考错题：到期回炉 > 没交手过）和「开炉炼丹」；
程序排的功课收在「师尊荐课」里，做不做自己定。「实战」就是原来的试炼塔（导航里不再单列）：宝塔只画当前层上下几层，
下面是整套试炼、板块试炼（闯关 / 回炉）、试炼战绩和导入真题。
斩心魔、试剑、化法为境判完不再直接结束：进入复盘，可以打字追问师傅，或点「🧙 师傅解惑」，师傅按这个板块的 skill 回答（带人设调侃）；
点「结束复盘」才收工（没连 AI 时只回一句台词）。

**藏经阁**分两殿：「📜 功法」每个板块一卷漂浮的线装古籍，点开看大项（口诀、思路、举例、掌握程度与训练入口）；
「💠 玉简 · 题库」每个板块一枚青玉简，点开是按知识点大类排的目录（“削弱论证-因果倒置”归在“削弱论证”下），
也可以在全部题库里搜（空格分开的关键词都要命中，可按板块、未做/做对/做错/待补筛），点一道展开题干和选项，
答案、解析和自己的作答记录（含用时）要点「显现」才出来。只读，不改题库（rpg/library.py，接口 /api/library*）。

**整套试炼**：练习册导入后编号是“前缀-套-题”（如 `大懒猫言语-03-07`），试炼塔顶部的「📚 整套试炼」按书列出各套，
点「开始 第NN套」就把这一套还没做的题按题号一次做完（不受每组 10/15 关限制）。一套跨板块也没关系——言语书一套里的片段阅读、
逻辑填空会按原顺序混在一起出。做完一套自动指向下一套；“选择其他套”可以跳着做。答案待补的题不出，补上答案后会接着出。
整套做完也算完成了当天这些板块的实战功课。

**历年真题（判断推理 7700 余题）**：来自考公脑库（github.com/ERRRC/kaogongzhentizhengliu）。`python -m rpg.zhenti <仓库目录> <输出目录>`
把 `10-真题/判断推理` 转成 `训练/题库/<板块>真题-历年.md`（每板块一份，和自己的 `<板块>真题.md` 分开；一个板块的所有 `<板块>真题*.md` 都会出题），
并写出 `题库/图片/真题库/图片清单.txt`，再从仓库的 `90-图片` 按清单拷图。编号 `真题-<qid>`；逻辑判断按考点分论证 / 形式（平行结构、日常结论归形式），
科学推理归常识判断。「整套试炼 → 历年真题」一张卷子的判断推理为一套（图形 → 定义 → 类比 → 逻辑），新卷在前。
作答前只显示题干和选项；作答后显示答案、官方解析、问法模型、推理链、最快解法、易错点、母题抽象。

**原题副本（政治理论 / 常识 / 言语 / 数量，1.5 万余题）**：来自 github.com/ERRRC/xingcezhenti。
`python -m rpg.zhenti --raw <仓库目录> <输出目录> [已有题库目录]` 生成 `<板块>真题-<年份>.md`（按年份拆）并把用到的图拷进 `题库/图片/真题库/`。
言语按题型分逻辑填空 / 片段阅读（语句表达归片段阅读），填空处的空格换成 `____`；有材料的题把材料接在题干前；多选题和非四选项题跳过。
联考各省卷共用的题只存一份，`### 试卷` / `### 题号` 一行一个、一一对应，几张卷子的整套试炼都会出它（做过一次各卷都算做过）。
整套试炼按“卷子 × 模块”成套（历年真题·言语理解与表达、历年真题·数量关系……），按原卷题号出题；解析里的公式图按行内小图显示。题库按文件修改时间缓存，大题库不用每次重读。
逐题选择答案后显示解析与知识点；每题立刻保存，中途暂停或重启后从同板块入口继续，组内题目使用开始时的快照。
错题自动收录，可从该板块的 **错题复练** 入口练习；默认连续正确两次移出待复练，历史不删除。
首次正确率、复练正确率、每组正确率单独显示，既有模考正确率与灵根判定保持原有口径。
实战不需要 AI，时间计入原有每日 120 分钟目标；首次作答及新题组通关按规则发修为，复练不重复发放。

旧存档启动时自动补充新的 bank 字段，升级不清空既有进度。新增规则缺失时使用默认值，配置版本仍为 3，
不触发整份规则重置；PowerShell 更新脚本只追加缺失的九个实战配置键，已有题库不会覆盖。
Windows 本地更新脚本见 `scripts/update-local.ps1`，运行前先关闭训练程序，脚本会备份训练目录到 `训练/更新备份/`。


### 实战的修仙／玄幻体验

导航为「试炼塔」（修仙／玄幻）；真题玉简／卷轴按顺序作为关卡，
错题化为心魔／魔物残影，进入伏魔再战／魔物再战独立复练。作答面板显示当前关卡、已答数、破关数、失手数；
师尊／学姐给出开场、答后与结算点评（不需要 AI，不改变客观答案）。
结算显示四档品评：全对、达到上品线、达到中品线、继续磨练。首次新题组通关基础奖励 30 修为／经验，
使用现有加成；复练不发通关奖。上版未结算组仅按带有新标记的首次作答比例奖励，旧战绩不补奖。
参数在规则中调整：试炼上品正确率 0.9、试炼中品正确率 0.7、经验.实战通关 30。
存档版本仍为 2；既有题号、历史答案和顺序进度沿用。更新脚本先备份，不改写存档，启动自动读取新规则默认值。


### 百层试炼塔

试炼塔在页面中显示完整的 100 层塔形，绿色为已登层、金色为正在攀登层。可滚动查看全部楼层，
或用「塔顶／定位当前层／塔底」快速定位。所有板块共用一座塔，默认登顶目标 5000 道新题，
每完成 50 道升一层：49 道还在攀登第一层，50 道登上第一层、开始攀登第二层，5000 道登顶。
首次提交即算完成一道，答错也计数；错题复练和重复提交不增加层数，正确率继续独立统计。
旧作答历史自动折算，不清零。题库陆续添加不会改变目标；层数与总目标题数可在规则.md 调整。
做题中也显示塔层进度，跨越层数门槛立即提示。层数不替代修为或境界，也不额外发升层奖励。

## 生成功法草稿读哪些资料

藏经阁“生成草稿”会读板块解题 skill，**以及 skill 里用反引号引用的库内资料**：比如政治理论 skill 引用的 `政治理论/00-三层级做题总框架.md`、`01-治理母逻辑` 文件夹、检索 skill 文件夹里的资料。skill 里“读哪个文件、调用哪个检索、输出格式、调度”这类写给 AI 的操作规程不会进骨架。
草稿开头会写“生成时读到的资料：……”。读得不对或缺了，在 `训练/规则.md` 加一行 `- 骨架素材.政治理论: 政治理论/00-三层级做题总框架.md, 政治理论/知识库`（库内路径，文件或文件夹，逗号隔开），再点“重新生成草稿”（未定稿的草稿会先备份成 .bak.md）。

## 每日功行 = 修炼 + 听道

每日目标默认 300 分钟（`规则.md` 的“每日目标分钟”），由两部分合计：
- **修炼**：在本程序里做功课的时间，自动计时（只算真正在做题 / 默写 / 论道的时间）。
- **听道**：在其他平台看网课的时间，首页「📿 听道 · 闻法记」手动记一笔（可选 30/60/90/120 快捷分钟、写讲的什么、补记最近 7 天、记错可删）。
打卡（周天不息）、道心、周常的功行分钟、导师“今日达标”都按合计算；听道每分钟给 0.5 修为（`经验.听道每分钟`），修为主要还是靠修炼。
旧版规则里仍是默认的“每日目标分钟: 120”“周常.修炼分钟: 600”会自动改成 300 / 1500，自己改过的值不动。
