# 行测修仙传（行测 RPG）

把行测复习做成一个修仙游戏的本地网页：用**费曼学习法 + 系统默写**把每个板块的“功法”（知识骨架）练到一个不漏说出来。
修为推动道行（预估分 50 → 80+），道行决定境界——凡人、炼气一至九层、筑基、金丹、元婴、化神、大乘、真仙；
突破大境界要**渡劫**，而且最近两次**宗门大比**（模考）都得达线。每个板块是一条**灵根**（天地玄黄八品，会跌落），
落后了去**丹房炼丹**加练，还有闭关、顿悟、走火入魔、道心、宗门周常、储物袋、飞升记录。
导师是接入 AI 的傲娇女仙师尊**劭神韵**，会结合你的实际进度现场说话。设置里可以一键切换成**西方玄幻风格**（导师艾琳学姐）。

- 只在自己电脑上运行（浏览器打开 `127.0.0.1`），数据放在 Obsidian 行测库的 `训练/` 文件夹，坚果云自动同步到另一台电脑；
- 只需要电脑上有 Python（Windows / Mac 都行），**不用安装任何别的东西**；
- AI（判默写、论道追问、判错题、生成功法、师尊说话和聊天）用你自己的 DeepSeek API key。

> 给其他 AI / 开发者：先读 [AGENTS.md](AGENTS.md) 和 [DESIGN.md](DESIGN.md)。

---

## 一、安装（只需在一台电脑上做一次）

1. 在 GitHub 仓库页面点 **Code → Download ZIP**，解压。
2. 在 Obsidian 行测库里新建文件夹 `训练/程序/`，把解压出来的**所有文件**复制进去。
   最后应该是：`行测/训练/程序/server.py`、`行测/训练/程序/rpg/`、`行测/训练/程序/web/` ……
   （放在库里，坚果云会同步到另一台电脑，两台都不用再装。）
3. 启动：
   - **Windows**：双击 `训练/程序/启动训练.bat`
   - **Mac**：双击 `训练/程序/启动训练.command`（第一次如果提示“无法打开”：右键 → 打开；
     或者在终端运行 `python3 "<库路径>/训练/程序/server.py"`）
4. 浏览器会自动打开训练页。第一次运行会在 `训练/` 里生成 `规则.md`、`角色设定.md`、`台词库.md`。
5. 点右上角 **设置**，填 DeepSeek 的 API key，点“测试 AI 连接”。
   **key 只保存在这台电脑**（`~/.xingce-rpg/settings.json`），另一台电脑要再填一次。

关掉黑色的终端窗口 = 关掉程序。

## 二、更新

重新 Download ZIP，把文件**覆盖**复制到 `训练/程序/`。你的数据在 `训练/` 下的其他文件夹里，不受影响。

程序升级如果改了配置文件的结构，会自动把你的 `规则.md` / `角色设定.md` / `台词库.md` 备份成 `xxx.旧版.md`
再换成新版（网页顶部会提示）。你改过的内容可以从旧版里抄回来。

## 三、怎么修炼

1. **藏经阁**：给当前秘境的板块点“编撰功法” → AI 从你的解题 skill 里提炼草稿 → 到 Obsidian 里审改
   `训练/骨架/<板块>.md` → 回网页点“定稿”。
2. **洞府**的“今日功课”每天自动生成：渡劫（条件满足时）→ 疗伤 → 温养道基 → 斩心魔 → 新修（背诵口诀 / 论道 / 试剑）。点一项就开始。
3. 每一重功法：背诵口诀连续过 2 次（小成）→ 论道过 1 次（大成）→ 试剑连续过 2 次（圆满），之后按 3/7/15/30/60 天温养。
4. 一个板块全部圆满 → 觉醒对应**灵根**；灵根品阶按该板块模考正确率算（天阶上品 ≥90%，常识 ≥80%），越熟的板块修为加成越高、温养间隔越长。
5. 每次模考出分后到**修仙录**记录宗门大比：最近两次的较低分若高于当前道行，修为直接补上（可以直接跨好几层）。
6. 修为到了 60 / 65 / 70 / 75 / 80 / 85 分线会进入**瓶颈**：最近两次大比达线 + 灵根达标 + 道心 ≥60 → 首页出现“渡劫”，
   连续扛过几道天雷才能突破；失败会道基受损，冷却 3 天并先疗伤。
7. 落后天道进度时去**丹房**炼丹（加练一炉，按成功率成丹、额外修为）；想专注一个板块就**闭关**。
8. 有事修炼不了：修仙录里用**告假玉简**（每月 4 份）。累了直接在对话框说“好累”，师尊会先安慰你。
9. 营地 / 洞府点“向师尊请教”：问方法、让她帮你分析现状排计划，她看得到你的全部进度。

## 四、改规则 / 人设 / 台词（不用改代码）

在 Obsidian 里改这些文件，保存后**刷新网页**就生效：

| 文件 | 改什么 |
|---|---|
| `训练/规则.md` | 目标日、境界分数线、渡劫条件与天雷数、灵根门槛与加成、丹药 / 闭关 / 顿悟 / 走火入魔、周常、分批、修为值…… |
| `训练/角色设定.md` | ID、头像（放进 `训练/`）；修仙 / 玄幻两种风格各自的称呼、导师名 / 头像 / 人设、吐槽尺度 |
| `训练/台词库.md`、`训练/台词库·玄幻.md` | 两位导师的备用台词（没连 AI 时用），随便加 |
| `训练/骨架/<板块>.md` | 功法（默写标准）：`## 大项`、`- 【术语】名称：解释`（口诀，一字不差）、`- 【思路】……`（说大意） |

想加新功能、改界面：把这个仓库交给 AI，让它先读 `AGENTS.md`。

## 五、常见问题

- **修炼时间怎么算**：只有打开一项功课（背诵、论道、试剑、斩心魔、渡劫、炼丹……）并且在操作时才计时，做完看解析的 3 分钟也算；
  只是开着网页、看面板、和师尊闲聊不算。顶栏的计时器在计时时会亮起闪烁。线下做题的时间到“修仙录 → 历练”手动补录。

- **打不开 / 闪退**：用终端运行 `python server.py`（Mac 用 `python3`）看报错。需要 Python 3.8 以上。
- **提示另一台电脑在用**：两台电脑同时开会让坚果云同步冲突，先关掉另一台上的程序（10 分钟后提示自动消失）。
- **提示有冲突副本**：`训练/存档/` 里出现带“冲突”的文件，说明两台同时写过。保留较新的那份，另一份删掉。
  每天第一次保存前都会自动备份到 `训练/存档/备份/`（保留 14 天）。
- **资料分析**：板块已预留（第 3 批）。把 `xingce-ziliao` skill 放进 `copilot/skills/` 后自动出现在技能树和分批里。
- **常识**：目前是“副线”，只统计模考实战正确率；常识知识库、错题自动归档在第二版（见 DESIGN.md 路线图）。


## 六、顺序真题实战

启动时自动创建 `训练/题库/`，包含现有 12 个板块的空白真题 Markdown 模板。
打开如 `论证逻辑真题.md`，将代码块内示例复制到代码块外，替换为你的真题。
每题用 `## 题目 固定编号`，包含 `### 知识点`、`### 题干`、`### 选项`、`### 答案`、`### 解析`；
选项是 A/B/C/D 单选，答案小节只写一个字母。每个板块内编号唯一、固定，程序按文档出现顺序做题，不按编号大小排序。
材料题将共同材料复制到各子题题干；目前按文本显示题目。

在 **实战题库** 选择每组 10 或 15 道；当天有骨架训练的板块会在最后一项知识训练后插入实战功课。
也可以直接从实战题库开始。剩余不足一组时做完剩余题，题库做完后等待你添加新题，不自动循环。
逐题选择答案后显示解析与知识点；每题立刻保存，中途暂停或重启后从同板块入口继续，组内题目使用开始时的快照。
错题自动收录，可从该板块的 **错题复练** 入口练习；默认连续正确两次移出待复练，历史不删除。
首次正确率、复练正确率、每组正确率单独显示，既有模考正确率与灵根判定保持原有口径。
实战不需要 AI，时间计入原有每日 120 分钟目标；首次作答及新题组通关按规则发修为，复练不重复发放。

旧存档启动时自动补充新的 bank 字段，升级不清空既有进度。新增规则缺失时使用默认值，配置版本仍为 3，
不触发整份规则重置；PowerShell 更新脚本只追加缺失的七个实战配置键，已有题库不会覆盖。
Windows 本地更新脚本见 `scripts/update-local.ps1`，运行前先关闭训练程序，脚本会备份训练目录到 `训练/更新备份/`。


### 实战的修仙／玄幻体验

导航为「试炼场」（修仙）／「试炼之塔」（玄幻）；真题玉简／卷轴按顺序作为关卡，
错题化为心魔／魔物残影，进入伏魔再战／魔物再战独立复练。作答面板显示当前关卡、已答数、破关数、失手数；
师尊／学姐给出开场、答后与结算点评（不需要 AI，不改变客观答案）。
结算显示四档品评：全对、达到上品线、达到中品线、继续磨练。首次新题组通关基础奖励 30 修为／经验，
使用现有加成；复练不发通关奖。上版未结算组仅按带有新标记的首次作答比例奖励，旧战绩不补奖。
参数在规则中调整：试炼上品正确率 0.9、试炼中品正确率 0.7、经验.实战通关 30。
存档版本仍为 2；既有题号、历史答案和顺序进度沿用。更新脚本先备份，不改写存档，启动自动读取新规则默认值。
