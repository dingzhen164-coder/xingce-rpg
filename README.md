# 行测修仙传（行测 RPG）

把行测复习做成一个修仙游戏的本地网页：用**费曼学习法 + 系统默写**把每个板块的“功法”（知识骨架）练到一个不漏说出来。
修为推动道行（预估分 50 → 80+），道行决定境界——凡人、炼气一至九层、筑基、金丹、元婴、化神、大乘、真仙；
突破大境界要**渡劫**，而且最近两次**宗门大比**（模考）都得达线。每个板块是一条**灵根**（天地玄黄八品，会跌落），
落后了去**丹房炼丹**加练，还有闭关、顿悟、走火入魔、道心、宗门周常、储物袋、飞升记录。
导师是接入 AI 的傲娇女仙师尊**劭神韵**，会结合你的实际进度现场说话。设置里可以一键切换成**西方玄幻风格**（导师艾琳学姐）。

- 只在自己电脑上运行（浏览器打开 `127.0.0.1`），数据放在 Obsidian 行测库的 `训练/` 文件夹，坚果云自动同步到另一台电脑；
- 只需要电脑上有 Python（Windows / Mac 都行），**不用安装任何别的东西**；
- AI（判默写、论道追问、判错题、生成功法、师尊说话和聊天）用你自己的 DeepSeek API key。

> 给其他 AI / 开发者：先读 [AGENTS.md](AGENTS.md) 和 [DESIGN.md](DESIGN.md)。

## 一、安装（只需在一台电脑上做一次）

1. 在 GitHub 仓库页面点 **Code → Download ZIP**，解压。
2. 在 Obsidian 行测库里新建文件夹 `训练/程序/`，把解压出来的**所有文件**复制进去。
   最后应该是：`行测/训练/程序/server.py`、`行测/训练/程序/rpg/`、`行测/训练/程序/web/` ……
   （放在库里，坚果云会同步到另一台电脑，两台都不用再装。）
3. 启动：
   - **Windows**：双击 `训练/程序/启动训练.bat`
   - **Mac**：双击 `训练/程序/启动训练.command`（第一次如果提示“无法打开”：右键 → 打开；
     或者在终端运行 `python3 "<库路径>/训练/程序/server.py"`）
4. 浏览器会自动打开训练页。第一次运行会在 `训练/` 里生成 `规则.md`、`角色设定.md`、`台词库.md`。
5. 点右上角 **设置**，填 DeepSeek 的 API key，点“测试 AI 连接”。
   **key 只保存在这台电脑**（`~/.xingce-rpg/settings.json`），另一台电脑要再填一次。

关掉黑色的终端窗口 = 关掉程序。

### 桌面版（exe，Windows）

不想开黑窗口、浏览器：到仓库的 **Releases** 下载 `xingce-xiuxian.exe`，放进 `训练/程序/`，双击就在自己的窗口里打开
（关掉窗口 = 退出）。exe 里自带 Python、拆 PDF 用的 pymupdf，不用装任何东西。
- 窗口用的是 Windows 自带的 Edge WebView2（Win10/11 一般都有）；万一窗口打不开，会自动改用浏览器。
- 启动信息、报错写在 `~/.xingce-rpg/启动日志.txt`。
- 第一次运行 Windows 可能提示“已保护你的电脑”：点“更多信息 → 仍要运行”（exe 没买签名证书）。

### Mac App（Apple 芯片：M 系列 / A 系列）

到 Releases 下载 `xingce-xiuxian-mac.zip`，解压出「行测修仙传」，拖进「应用程序」（**不要**放进坚果云同步的文件夹）。
- 第一次打开会提示“无法验证开发者”（没买苹果的开发者证书）：系统设置 → 隐私与安全性 → 往下找到「仍要打开」；
  或者在终端运行一次 `xattr -cr /Applications/行测修仙传.app` 再双击。
- App 不在库里，会自己到坚果云同步文件夹、桌面、文稿里找行测库，找到就记住；找不到就到 设置 → 库路径 填一次。
- 读成绩截图用苹果自带的 Vision 认字，和 Windows 一样能自动填成绩单。
- 本机设置（AI 的 key 等）每台电脑各存一份，Mac 上要再填一次。**两台电脑别同时开着修仙传**（坚果云同步有延迟，存档会互相覆盖）。
- 更新：设置 → 🆕 版本与更新 → 检查更新 → 到 GitHub 下载新的 zip，替换「应用程序」里的旧版。

### 手机 / 平板（局域网模式）

电脑当主机，同一个 Wi-Fi 下的手机、平板用浏览器打开，数据只存电脑上这一份：
1. 电脑上 **设置 → 📱 手机 / 平板**，勾上“允许手机 / 平板连进来”，**重启程序**（源码版也可以 `python server.py --lan`）；
   Windows 防火墙弹窗点“允许”。
2. 手机扫设置页里的二维码，或者在浏览器输入那里显示的地址（`http://192.168.x.x:8765/`），输一次 6 位访问口令。
3. **安卓平板 / 手机：装「行测修仙传」App**（Releases 里的 `xingce-xiuxian.apk`，平板浏览器打开设置页也有下载按钮）。
   打开后它在 Wi-Fi 里自己找到电脑，全屏、没有浏览器的地址栏和工具栏；记住地址，下次直接进。
   返回键：先关弹窗 / 画面，再回洞府，在洞府按两次退出。源码在 `android/`，版本号跟 `rpg/version.py` 一起走。
   苹果：Safari「分享 → 添加到主屏幕」，从桌面图标打开就是全屏。电脑要开着、修仙传要在运行。

口令和局域网开关只能在电脑上改；“换一个”口令后，连过的设备要重新输。

## 二、更新

**exe 版**：设置 → 🆕 版本与更新 → 检查更新 → 「更新并重启」，自动下载新 exe、换掉旧的、重新打开。
（发布方式：改 `rpg/version.py` 的版本号推到 main，GitHub Actions 会在 Windows 上打包 exe 发到 Releases，
见 `.github/workflows/build-exe.yml`；也可以在 Actions 页手动运行。）

**源码版**：重新 Download ZIP，把文件**覆盖**复制到 `训练/程序/`。你的数据在 `训练/` 下的其他文件夹里，不受影响。

程序升级如果改了配置文件的结构，会自动把你的 `规则.md` / `角色设定.md` / `台词库.md` 备份成 `xxx.旧版.md`
再换成新版（网页顶部会提示）。你改过的内容可以从旧版里抄回来。

## 三、怎么修炼

1. **修炼殿 · 📜 玉简**（照 Anki 做的记忆卡片，2.1.0 起取代原来的传授 / 背诵 / 论道 / 化法为镜 / 试剑）：
   - **简匣**（牌组）：默认建好 12 个板块的空匣，子匣用 `::` 隔开（如「资料分析::速算公式」）；每行显示 新简 / 参悟中 / 待温 三个数，点名字开始温这个匣（含子匣），⚙ 里是简匣规矩、新建子匣、改名、删除。
   - **✍ 刻简**（加卡片）：选简匣、类型（问答 / 问答 + 反向 / 填空 `{{c1::…}}`）、写正反面和标签；图片可以直接粘贴，也能「✍ 手写」；Ctrl+Enter 刻入，窗口不关接着刻。
   - **🌙 温简**（复习）：先看正面 → 空格「显示答案」→ 四个评分 **再参 / 晦涩 / 通透 / 了然**（= Anki 的 重来 / 困难 / 良好 / 简单，按钮上写着下次间隔），键盘 1~4，Ctrl+Z 撤销；翻面后「🙋 师傅讲讲」可以请 AI 讲这张卡、接着追问。排期用 FSRS（Anki 现在的默认算法）。
   - **⚙ 简匣规矩**：每天新简数、每天复习上限、学习 / 重参步长、目标记忆保持率（默认 0.9）、忘几次算顽固、最长间隔；没单独设的沿用上层。
   - **🏛 藏简阁**：搜索、筛选（新简 / 今日到期 / 暂停 / 顽固），点一行改简，勾选后批量暂停 / 恢复 / 重置为新 / 移动 / 删除，ℹ 看温习记录。
   - **🧙 师傅制卡**：上传 PDF / Markdown / TXT（或选库里的笔记、粘贴文字）→ 勾章节或填页码 → AI 按“一张卡只考一个点”出草稿 → 页面上审、改、删 → 勾上的一次刻入（每张附注写出处）。扫描版 PDF 要填识图模型。
   - **📊 灵识图**：温简热力、未来 30 天到期、记住率、评分分布。**📥 导入**：Anki 导出的纯文本（正面⇥反面⇥标签）或 anki-expert 的卡片表格。
   - 玉简存在库里 `训练/卡片/<顶层简匣>.md`，Obsidian 里能看能改（`## 玉简 编号` 那行别改），坚果云同步；温习进度在存档里，改内容不丢进度。
     xingce-card skill 从 PDF / 笔记做的卡也写成这个格式。温简的时间算「修炼 · 复习」，每温一枚得少量修为。
   - **⚙ 每天 新简 · 复习**（玉简右上角）：全部简匣每天学多少新简、复习多少；单个匣子在它的 ⚙ 里另设。
   - 「🙋 师傅讲讲」只帮着记（口诀、联想、对比、例子），不评判卡片；讲过的存进玉简的 `### 师傅讲讲`，翻面时可以展开再看。
2. **修炼殿 · 🌿 灵脉图**（玉简下面）：每个板块的思维导图（编辑器是开源的 simple-mind-map）。点板块的阵盘打开，
   加子节点 / 同级（Tab / Enter）、删除、双击改字、拖动换位置、撤销，六种布局；导入 .xmind / Markdown / JSON，导出 XMind / 图片 / Markdown / JSON（训练/灵脉图/导出/）。
   存在 `训练/灵脉图/<板块>/<名字>.json`，一个板块可以有好几幅。
   - 下面是 **👹 斩心魔**：模考错题，按板块一只只斩。
2. **洞府**的“今日功课”（师尊荐课）每天自动生成：渡劫（条件满足时）→ 疗伤 → 温简（今天到期的玉简）→ 斩心魔 → 当前秘境板块的真题试炼。点一项就开始。
3. 功法（`训练/骨架/<板块>.md`）还在藏经阁里，丹房炼丹、渡劫的关卡仍会用到。
4. 一个板块全部圆满 → 觉醒对应**灵根**；灵根品阶按该板块模考正确率算（天阶上品 ≥90%，常识 ≥80%），越熟的板块修为加成越高、温养间隔越长。
5. 洞府里三张同版式的记录卡，颜色对应三才时辰：**听道 · 闻法记**（听课，青）、**演武 · 历练记**（自己做题，朱）、**静修 · 温养记**（自己复习：背口诀、看笔记、整理错题本，金）。
   静修填几分钟、模块、复习了什么、心得，分钟算进「复习」，写进 `训练/静修录/<年-月>.md`。
   纸质资料、其他 App 上自己做题记在**演武 · 历练记**：板块、资料、题数/对几题/分钟，加一段日志
   （写进 `训练/演武录/<年-月>.md`，旧版的 `训练/红尘历练/` 会自动改名过去，只写日志题数留空即可），下面折叠着近 7 天记录（题数、正确率、用时、每题秒数、资料、心得，记错可删，可补记 7 天内）；碰到好题，到**修仙录 →「📥 好题收进题库经卷」**
   填题干、四个选项、答案、解析，追加到 `训练/题库/<板块>真题.md`（编号 `自练-日期-序号`），之后试炼、知识点试炼、经卷搜索都能用（答案不填就先“待补”）。
   洞府英雄卡下面是**三才时辰**：听课（听道）、做题（试炼、斩心魔、试剑、炼丹、渡劫 + 自练）、复习（传授、背诵口诀、论道、温养）三枚法印，
   外圈亮弧是占总时长的比例，可切今日 / 近七日 / 累计；下面的比例条以听课为 1（如“听课 1 : 做题 1.5 : 复习 0.5”），白色刻度每格一份听课时长。
   以前没分类的修炼时间都算复习。
   三才时辰下面（闻法记之前）是**十二经 · 各模块时辰**：十二个模块（十一部功法 + 常识判断）各一枚同款圆形法印、各一种颜色，一排四枚（手机上两枚），
   显示这个模块的总时长、占比，下面小字分听 / 题 / 复；可切今日 / 近七日 / 累计。修炼里的时间按当时在练的模块记
   （知识点试炼算它的板块，整套试炼按当前这道题的板块），自练按选的板块，听道记录时可以选模块（不选就只算进三才时辰）。
   早先没记模块的修炼时间，按那天 `训练/修炼记录/<板块>/` 里的对话段落和修炼事件里各模块练了几次按比例分摊，实在认不出的写在卡片底部。
   听道没选模块时从“讲的什么”里认（写了板块名或“图推”“资料”“数量”“常识”等简称），近 7 天听道记录每条后面有模块下拉框，认错了直接改。
   **收功结算**：记一笔听道、记一笔自练，或在修炼里做完一项复习（传授、背诵、论道、温养…）/ 实战（试炼、斩心魔、试剑、炼丹、渡劫）后，
   弹出一幕结算：你的头像接一身道袍（换头像会跟着换），听课、复习是悬空打坐，做题是站立，双手结剑诀；周身是对应颜色的灵光
   （听课青、做题朱、复习金），头后光轮、脚下八卦法阵缓转、灵气上升；右边是今日功行和修为两条进度条从之前涨到之后（+分钟、+修为），
   境界变了也会写出来。点「收功」、点空白处或 Esc 关闭（web/settle.js）。
6. 每次模考出分后到**修仙录**记录宗门大比：最近两次的较低分若高于当前道行，修为直接补上（可以直接跨好几层）。
7. 修为到了 60 / 65 / 70 / 75 / 80 / 85 分线会进入**瓶颈**：最近两次大比达线 + 灵根达标 + 道心 ≥60 → 首页出现“渡劫”，
   连续扛过几道天雷才能突破；失败会道基受损，冷却 3 天并先疗伤。
8. 落后天道进度时去**丹房**炼丹（加练一炉，按成功率成丹、额外修为）；想专注一个板块就**闭关**。
9. 有事修炼不了：修仙录里用**告假玉简**（每月 4 份）。累了直接在对话框说“好累”，师尊会先安慰你。
10. 营地 / 洞府点“向师尊请教”：问方法、让她帮你分析现状排计划，她看得到你的全部进度。

**换 AI**：设置 → 🤖 当前 AI。几套 AI（接口地址 + 模型 + key）各「存为一套」，下拉一选就切换；「常用接口」可一键填好 DeepSeek、通义千问、Kimi、智谱、硅基流动、OpenAI 的接口地址。

## 五、常见问题

- **修炼时间怎么算**：只有打开一项功课（背诵、论道、试剑、斩心魔、渡劫、炼丹……）并且在操作时才计时，做完看解析的 3 分钟也算；
  只是开着网页、看面板、和师尊闲聊不算。顶栏的计时器在计时时会亮起闪烁。线下做题的时间到“洞府 → 演武 · 历练记”手动补录。

- **打不开 / 闪退**：用终端运行 `python server.py`（Mac 用 `python3`）看报错。需要 Python 3.8 以上。
- **提示另一台电脑在用**：两台电脑同时开会让坚果云同步冲突，先关掉另一台上的程序（10 分钟后提示自动消失）。
- **提示有冲突副本**：`训练/存档/` 里出现带“冲突”的文件，说明两台同时写过。保留较新的那份，另一份删掉。
  每天第一次保存前都会自动备份到 `训练/存档/备份/`（保留 14 天）。
- **图形推理**：程序自带薛睿图推 24 诀功法（`训练/骨架/图形推理.md`），每一诀练三件事——适用图形的特征、口诀原句（一字不差）、口诀翻译。
  第一次运行会复制成草稿，对照原资料核对完标 ⚠ 的地方再定稿。
- **资料分析**：程序自带“题型识别 + 公式速算”功法（`训练/骨架/资料分析.md`，第 3 批），一个 `##` = 一种题型，每种练两件事——
  【识别】看到题干哪些信号就知道是这个题型；【公式】/【速算】这个题型的公式和简便算法。`> 真题例：` 行是原资料的真题题干，不判分。
  试剑是“识别速答”：师尊只出一句题干，你说出题型、识别依据、公式、速算方法，不用算数。
  如果库里已经有按 skill 生成的 `资料分析.md`，不会被覆盖，程序自带那份会放在旁边叫 `资料分析.程序自带版.md`，想用就改名替换。
- **常识**：目前是“副线”，只统计模考实战正确率；常识知识库、错题自动归档在第二版（见 DESIGN.md 路线图）。

## 六、顺序真题实战

启动时自动创建 `训练/题库/`，包含现有 12 个板块的空白真题 Markdown 模板。
打开如 `论证逻辑真题.md`，将代码块内示例复制到代码块外，替换为你的真题。
每题用 `## 题目 固定编号`，包含 `### 知识点`、`### 题干`、`### 选项`、`### 答案`、`### 解析`；
选项是 A/B/C/D 单选，答案小节只写一个字母。每个板块内编号唯一、固定，程序按文档出现顺序做题，不按编号大小排序。
材料题将共同材料复制到各子题题干。

**批量入库**：试炼塔页面的「📥 导入真题」，不用 AI 逐题核对、几秒钟入库：
- **模考**：在「① 模考」点「选择文件」选粉笔模考 PDF，点「拆分并导入」——程序自动存进 `FB模考试卷复盘/模考试卷/`、调用 xingce-mokao-split 拆成板块复盘（和以前做复盘一样），再导入试炼塔。不用记命令。文件名没有“第X季”时填一下第几季。第一次用要点「安装拆分组件」（pymupdf，只装一次）。已经拆好的季在下面列出，点「导入」。题干、选项、答案、截图都来自 PDF 原文，
  来源自动写“（粉笔第36季模考）”，截图复制到 `训练/题库/图片/<板块>/`。导过的题再点也不会重复。
- **txt**：练习册、真题卷的 OCR 文字。选文件，填编号前缀（如“四海逻辑600”），来源能认出就自动写，练习册勾“没有来源”。
- **PDF（有文字层）**：WPS / Word 导出的、或 OCR 软件生成的“可搜索 PDF”，在同一处直接选。比转 txt 多保住逻辑填空的横线（写成 `____`）和双空选项之间的空格。“拔高刷题十一”“练习题16”这类标记按里面的数字分套。扫描图片 PDF 没有文字层，要先 OCR 成可搜索 PDF。需要 pymupdf（① 里的“安装拆分组件”）。
  能干净拆开的题直接入库，拆不干净的放进 `训练/题库/_待修/<名称>.md`：在 Obsidian 里改好、清空那道题的“### 检查”，回来点「重新导入」；修不了就删掉。
  粉笔试卷的 OCR 文字顺序会乱，请改用上面的“模考”方式。
- **补答案**：练习册答案在另一本时。整本一次补：前缀填导入时的前缀（如“花生600题”），答案每行一套“练习01 ADDBA CDCAB DBBCC BBADD”；
  只补一套：前缀写到第几套（如“花生600题-03”），答案写“1-5 ABCDA”或“1.A 2.B”。练习册按每套开头的“练习题NN”分套，套号和答案表对得上。
- **撤销一批**：导错了想重导时，填编号前缀删除这批还没做过的题（做过的有作答记录，保留）。
- **知识点**：按问法自动猜（削弱、加强、真假推理……），猜不出写“待分类”，不影响做题；设置了 DeepSeek 可以点「AI 补 100 题」，
  只发题干给 AI（有骨架的板块用骨架的大项名），几百道题几毛钱。
- 想让 AI 精修个别题时，还可以用 obsidian-to-xingce 仓库的 `xingce-tiku` skill（费 token，一般用不到）。
- **图**：图形推理、资料分析的图放在 `训练/题库/图片/<板块>/`，题干里写 `![[训练/题库/图片/图形推理/编号.png]]`，试炼时会显示图片。
- **答案待补**：`### 答案` 写“（待补）”的题先不出，题库页显示“待补答案 N 道”。
- **解析待补**：`### 解析` 可以写“（待补）”，作答后显示“解析待补”，之后再用 skill 补。

在 **试炼塔** 选择每组 10 或 15 道，出题可选「按顺序 / 🔀 乱序」（板块试炼和知识点试炼共用；乱序从还没做过的题里随机抽，做过的照样不出）；当天有骨架训练的板块会在最后一项知识训练后插入实战功课。
也可以直接从实战题库开始。剩余不足一组时做完剩余题，题库做完后等待你添加新题，不自动循环。

**交卷式试炼**：点选项作答的组（板块组、整套试炼、错题复练）全部选完点「交卷」才判分：可以翻回去改答案，答题时不显示对错。
交卷后给正确率、品评、答题卡，师尊按成绩调侃一句，然后逐题复盘（题干、你的答案、正确答案、解析），可跳“下一道错题”。
师傅解惑 / 复盘追问 / 传授读的是 skill 文件夹里**所有** .md（SKILL.md、chapters、references……，scripts 不读）加上 skill 里引用的库内资料（上限 6 万字，超出的写明未读）；讲题必须先点名用 skill 里的哪个方法 / 哪类关系、题干里的线索词，每个空都要，再按步骤推；原解析只给官方部分（蒸馏补的推理链、最快解法……和以前的师傅解惑不给），只用来核对答案和词义；讲完在下面标出这次依据了哪些 skill 文件，没找到 skill 也会提示。
复盘时底部有聊天框，对这道题有疑问直接打字问师傅（带着题干、选项、答案、你选的和原解析），每道题各自一段对话；
「🧙 师傅解惑」按钮保留，专门跑 skill：把这道题和所属板块的 skill（常识判断用 xingce-changshi）发给 AI，按功法讲题并带人设调侃，
讲解**写进题库里这道题的 `### 解析` 末尾**（一段“【师傅解惑】（日期）”，原解析保留；再问一次换成新的；补蒸馏解析时也保留它），
以后复盘、藏经阁经卷、Obsidian 里打开题库都能看到；`训练/题库/师傅解惑.md` 仍留一份备份。没连 AI 时只说一句台词。复盘中途可“稍后再看”，再进来还在复盘。所有板块（包括论证逻辑）默认都这样答；“写拆题过程、AI 逐题审方法”的模式只在功课里带 reasoning 时才用。
计时：每道题从显示到离开记一次（翻回来改答案的时间也算这道题，单次最多记 10 分钟，暂离不计），战斗面板实时走秒；
交卷后给成绩表（题、编号、板块、知识点、我选、答案、对错、用时，跨板块再按板块汇总），结束复盘时再给一次，
并追加到 `训练/试炼记录/<日期>.md`；试炼战绩里显示每组用时。
新台词场景：试炼·没做完 / 全对 / 上品 / 中品 / 下品 / 复盘错题 / 复盘结束 / 解惑没AI；自己的台词库里没有的场景自动用默认台词。

辨析（解析里讲这个空的那段）、真题（点「↗ 编号」跳到经卷里这道题并直接展开题干，有「← 回成语实词录」）。同一个词再考到就在词条下多挂一条出处。

Obsidian 里也能点）；数据在存档的 idioms 里（rpg/idioms.py、web/idioms.js）。

**原题副本（政治理论 / 常识 / 言语 / 数量，1.5 万余题）**：来自 github.com/ERRRC/xingcezhenti。

### 百层试炼塔

试炼塔在页面中显示完整的 100 层塔形，绿色为已登层、金色为正在攀登层。可滚动查看全部楼层，
或用「塔顶／定位当前层／塔底」快速定位。所有板块共用一座塔，默认登顶目标 5000 道新题，
每完成 50 道升一层：49 道还在攀登第一层，50 道登上第一层、开始攀登第二层，5000 道登顶。
首次提交即算完成一道，答错也计数；错题复练和重复提交不增加层数，正确率继续独立统计。
旧作答历史自动折算，不清零。题库陆续添加不会改变目标；层数与总目标题数可在规则.md 调整。
做题中也显示塔层进度，跨越层数门槛立即提示。层数不替代修为或境界，也不额外发升层奖励。

## 生成功法草稿读哪些资料

藏经阁“生成草稿”会读板块解题 skill，**以及 skill 里用反引号引用的库内资料**：比如政治理论 skill 引用的 `政治理论/00-三层级做题总框架.md`、`01-治理母逻辑` 文件夹、检索 skill 文件夹里的资料。skill 里“读哪个文件、调用哪个检索、输出格式、调度”这类写给 AI 的操作规程不会进骨架。
草稿开头会写“生成时读到的资料：……”。读得不对或缺了，在 `训练/规则.md` 加一行 `- 骨架素材.政治理论: 政治理论/00-三层级做题总框架.md, 政治理论/知识库`（库内路径，文件或文件夹，逗号隔开），再点“重新生成草稿”（未定稿的草稿会先备份成 .bak.md）。

## 每日功行 = 修炼 + 听道

每日目标默认 300 分钟（`规则.md` 的“每日目标分钟”），由两部分合计：
- **修炼**：在本程序里做功课的时间，自动计时（只算真正在做题 / 默写 / 论道的时间；在 🪶 手札里写字也算复习，停笔超过 1 分钟就不再计）。
- **听道**：在其他平台看网课的时间，首页「📿 听道 · 闻法记」手动记一笔（可选 30/60/90/120 快捷分钟、写讲的什么、补记最近 7 天、记错可删）。
打卡（周天不息）、道心、周常的功行分钟、导师“今日达标”都按合计算；听道每分钟给 0.5 修为（`经验.听道每分钟`），修为主要还是靠修炼。
旧版规则里仍是默认的“每日目标分钟: 120”“周常.修炼分钟: 600”会自动改成 300 / 1500，自己改过的值不动。
