# 行测修仙传 · 版本更新记录

每次改 rpg/version.py 的版本号，都在最上面加一节（tests/test_device.py 会检查最新一节和版本号对得上）。
设置 → 🆕 版本与更新 → 「版本更新记录」读的就是这个文件。

## 2.4.0 · 2026-10-07
- 🌿 新功能「灵脉图」：修炼殿玉简下面，每个板块一枚会动的灵脉阵盘，点开是思维导图（XMind 那样的）
  - 自己画：加子节点 / 同级、删除、双击改字、拖动换位置、撤销重做；六种布局（逻辑结构、思维导图、组织结构、目录、时间轴、鱼骨图）
  - 导入 .xmind / Markdown / JSON（导成新的一幅）；导出 XMind / 图片 / Markdown / JSON 到 训练/灵脉图/导出/
  - 一个板块可以画好几幅；改了自动保存在 训练/灵脉图/<板块>/，坚果云同步
- 🙋 师傅讲讲只帮你记：给口诀、联想、对比、例子，不再评判卡片内容对不对、不另外塞新内容
- 师傅讲过的自动存进这枚玉简（Obsidian 里是“### 师傅讲讲”），翻面时「🙋 师傅讲过 N 次」点开就能再看
- 温简页面开着就算复习时间（不用非得每两分钟答一张）
- 玉简右上角加了「⚙ 每天 新简 20 · 复习 200」：一处设全部简匣每天学多少新简、复习多少；单个匣子还能在它的 ⚙ 里另设

## 2.3.0 · 2026-10-07
- 手札去掉「🧙 师傅编纂」，换成「📄 导出 PDF」：整本连纸（横线 / 方格）带字存成 A4 PDF，放在 训练/手札/导出/本子名.pdf（同名覆盖，末尾没写字的空白页不导出）
  - 电脑上点「打开」直接用默认的 PDF 阅读器打开；平板上点「下载到这台设备」交给系统浏览器下载（要先更新平板 App）
- 设置里的识图模型改成给「🧙 师傅制卡」读扫描版 PDF 用

## 2.2.0 · 2026-10-07
- 🧙 师傅制卡：修炼殿玉简下面新按钮。上传 PDF（书、讲义）/ Markdown / TXT，或选库里的笔记（含手札编纂的）、或粘贴文字 →
  勾选要做的章节（PDF 书签目录）或填页码 → 选简匣、卡片类型、出多少 → 师傅一段一段出玉简草稿（显示进度，可中途停）→ 在页面上审、改、删 → 勾上的一次刻入
  - 出卡规则：一张卡只考一个点、答案有几条在问题里写明、补对比卡、关键词出填空卡；公式卡写“什么时候用 + 例子”，不抄整道题
  - 每张卡的附注写着出处（哪本书第几页）；扫描版 PDF 要在设置里填识图模型
- ⚙ 设置 → 🤖 当前 AI：把几套 AI（DeepSeek、通义千问、Kimi、智谱……）各存一套，下拉一选就切换；「常用接口」一键填好接口地址和模型

## 2.1.0 · 2026-10-07
- 修炼殿重做成「📜 玉简」（照 Anki 的记忆卡片），原来的传授、背诵、论道、化法为镜、试剑拿掉：
  - 简匣（牌组）树：默认 12 个板块，可建子匣；每匣显示 新简 / 参悟中 / 待温，点名字开始温
  - ✍ 刻简：问答、问答 + 反向、填空（{{c1::…}}）三种；可粘贴图片、手写；刻完窗口不关接着刻
  - 🌙 温简：显示答案 → 再参 / 晦涩 / 通透 / 了然 四个评分（按钮上写着下次间隔），键盘 空格 / 1~4 / Ctrl+Z；翻面后「🙋 师傅讲讲」可以请 AI 讲解、追问
  - 排期用 FSRS（Anki 现在的默认算法）；⚙ 简匣规矩可设每天新简数、复习上限、步长、目标记忆保持率
  - 🏛 藏简阁（搜索、批量暂停 / 移动 / 删除、温习记录）、📊 灵识图（热力图、到期预测、记住率）、📥 导入 Anki 导出的文本
  - 玉简存在库里 训练/卡片/，Obsidian 里能看能改；温简时间算进「修炼 · 复习」，每温一枚得少量修为
- 师尊荐课改成：温简、斩心魔、当前秘境的真题试炼（不再排背诵 / 论道 / 试剑）
- 藏经阁的题库改名「📖 经卷」，免得和玉简混了
