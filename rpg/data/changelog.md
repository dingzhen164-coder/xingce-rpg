# 行测修仙传 · 版本更新记录

每次改 rpg/version.py 的版本号，都在最上面加一节（tests/test_device.py 会检查最新一节和版本号对得上）。
设置 → 🆕 版本与更新 → 「版本更新记录」读的就是这个文件。

## 1.4.0 · 2026-10-04
- 做题、复盘时题目钉在对话框顶上：往下翻解析、师傅的讲解，题目不动，方便对照；题目太长时在框里单独滚动，📌 可以把它收成一行
- 设置里加了「版本更新记录」（可折叠），记下每一次更新改了什么

## 1.3.5 · 2026-10-04

- 设置 → 对话框大小与字体：可调对话框字号（80%~160%，默认 110%），电脑、平板各调各的
